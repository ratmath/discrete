Codes and designs

Error-correcting codes

Add redundancy to a message so that a few corrupted symbols can be found and fixed. A linear code is a subspace of \(\mathbb{Z}_p^n\); its minimum distance says how many errors it can correct, and its parity-check matrix says where they are.

The Hamming code

import { hammingCode, isPerfect } from "@ratmath/discrete";

const h = hammingCode(3);         // [7, 4] over Z_2
h.minimumDistance().distance;     // 3: corrects one error
isPerfect(h);                     // true
const cw = h.encode([1, 0, 1, 1]);   // [1, 0, 1, 1, 0, 1, 0]
h.decode([1, 0, 0, 1, 0, 1, 0]).steps;
// ["received 1001010", "syndrome H·rᵀ = 110",
//  "the lightest error with that syndrome is 0010000 (weight 1)", "corrected codeword 1011010, message 1011"]

A code with generator matrix \(G\) (\(k \times n\)) encodes \(m\) as \(mG\). Put \(G\) in systematic form \([I_k \mid A]\); then \(H = [-A^{\top} \mid I_{n-k}]\) satisfies \(G H^{\top} = 0\), and a word \(r\) is a codeword exactly when its syndrome \(Hr^{\top}\) is zero. If \(r = c + e\), the syndrome is \(He^{\top}\), so decoding is finding the lightest error with that syndrome, the coset leader. In the Hamming code the columns of \(H\) are all non-zero vectors, so the syndrome of a single error is its position written in binary.

Distance and bounds

A code with minimum distance \(d\) corrects \(t = \lfloor (d-1)/2 \rfloor\) errors, because balls of radius \(t\) round the codewords do not overlap. Counting the words in those balls gives the Hamming (sphere-packing) bound, and a code that meets it is perfect:

\[ |C| \cdot \sum_{i=0}^{t} \binom{n}{i}(q-1)^i \le q^n. \] 
import { codeBounds, ballSize } from "@ratmath/discrete";
codeBounds(7, 3, 2);   // { hamming: 16n, singleton: 32n, gilbertVarshamov: 5n }
ballSize(7, 1);        // 8n, and 16 · 8 = 2^7: the Hamming code is perfect
h.weightDistribution();             // [1, 0, 0, 7, 7, 0, 0, 1]
h.dual().minimumDistance().distance;   // 4: the [7, 3] simplex code

Reed–Solomon

import { reedSolomon } from "@ratmath/discrete";
const rs = reedSolomon({ p: 11, n: 10, k: 4 });   // corrects 3 errors
const w = rs.encode([3, 1, 4, 1]);                // the values of 3 + x + 4x² + x³ at 1, …, 10
const y = w.slice(); y[0] += 1; y[5] += 3; y[9] += 7;   // three errors (mod 11)
rs.decode(y.map((v) => v % 11)).errors;           // [0, 5, 9]

A message is a polynomial \(f\) of degree below \(k\), sent as its values at \(n\) distinct points. Two such polynomials agree in at most \(k - 1\) places, so the distance is \(n - k + 1\), meeting the Singleton bound. Berlekamp–Welch decoding looks for an error locator \(E\) of degree \(e\) (monic) and \(Q\) of degree below \(e + k\) with \(Q(\alpha_i) = y_i E(\alpha_i)\) for every \(i\): a linear system over \(\mathbb{Z}_p\). Then \(f = Q / E\), and \(E\) vanishes at the error positions. The steps show the system, \(E\), \(Q\) and the division.
