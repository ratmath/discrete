Graph theory

Planarity

A graph is planar when it can be drawn in the plane without crossings. Kuratowski's theorem says the only obstructions are subdivisions of K5K_5K5​ and K3,3K_{3,3}K3,3​, so every answer here comes with evidence: faces for yes, one of those two subgraphs for no.

Yes, with faces

import { complete, planarity, isPlanar, hypercube, platonic } from "@ratmath/discrete";

planarity(complete(4));
// { planar: true, faces: [[[3,1,4], [4,3,2], [1,4,2], [2,3,1]]], edges: 6, vertices: 4 }
isPlanar(platonic("icosahedron"));   // true
isPlanar(hypercube(4));              // false

Each 2-connected block is embedded by the Demoucron–Malgrange–Pertuiset algorithm: start from a cycle, and repeatedly route a piece of the remaining graph through a face that holds all its attachment points, choosing a piece that fits in the fewest faces first. Faces are listed per block. Euler's formula is the check on every block:

V−E+F=2. V - E + F = 2. V−E+F=2.

For K4K_4K4​: 4−6+4=24 - 6 + 4 = 24−6+4=2.

No, with a Kuratowski subgraph

import { petersen, checkKuratowski } from "@ratmath/discrete";
const r = planarity(petersen());
r.kuratowski.kind;     // "K3,3"
r.kuratowski.branch;   // the six branch vertices
r.kuratowski.paths;    // nine paths joining them, internally disjoint
checkKuratowski(petersen(), r.kuratowski).ok;   // true

When the embedding fails, edges are deleted one at a time while the graph stays non-planar. What is left is edge-minimal non-planar, and by Kuratowski's theorem it is a subdivision of K5K_5K5​ or K3,3K_{3,3}K3,3​: the vertices of degree three or four are the branch vertices and the rest lie on paths between them. checkKuratowski confirms the paths use real edges, are disjoint apart from their ends, and join the right pairs.

Quick counting arguments

A simple planar graph with V≥3V \ge 3V≥3 has E≤3V−6E \le 3V - 6E≤3V−6, since every face has at least three edges and each edge borders two faces. Without triangles it is E≤2V−4E \le 2V - 4E≤2V−4. So K5K_5K5​ (10 > 9) and K3,3K_{3,3}K3,3​ (9 > 8) are out at once; Petersen has 15 edges, within both bounds, and needs the search.
