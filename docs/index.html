@ratmath/discrete

Counting, graphs and games, exactly

Combinatorics, graph theory and game theory in one library: exact counts of any size, objects you can list, rank and sample, graph algorithms with certificates, and games solved in exact fractions.

Planned, not built yet. This site is the frame the package will grow into. The full plan is in the library roadmap, and the RatMath Shelf page lists what exists across all the libraries.

What it will cover

  • Counting: binomials, Stirling and Catalan numbers, partitions, inclusion and exclusion.
  • Enumeration with ranking and unranking, and a seeded random generator shared with statistics.
  • Graphs: structure, traversal, shortest paths, trees, standard families.
  • Generating functions and recurrences, solved in closed form.
  • Matchings, flows, colouring, planarity, isomorphism and spectra.
  • Exact linear programming, and matrix and bimatrix games.
  • Combinatorial, extensive-form and cooperative games; voting.
  • Sets, relations and partial orders; Pólya counting; codes and designs.

How the docs will be laid out

Like every library on the Shelf: this overview, an Explore page for trying things without writing code, a Reference listing every function, and one page per topic that explains the usage and the mathematics. Every page ends with a box of code you can edit and run.
