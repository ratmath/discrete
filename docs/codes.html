Codes and designs

Error-correcting codes

Add redundancy to a message so that a few corrupted symbols can be found and fixed. A linear code is a subspace of Zpn\mathbb{Z}_p^nZpn​; its minimum distance says how many errors it can correct, and its parity-check matrix says where they are.

The Hamming code

import { hammingCode, isPerfect } from "@ratmath/discrete";

const h = hammingCode(3);         // [7, 4] over Z_2
h.minimumDistance().distance;     // 3: corrects one error
isPerfect(h);                     // true
const cw = h.encode([1, 0, 1, 1]);   // [1, 0, 1, 1, 0, 1, 0]
h.decode([1, 0, 0, 1, 0, 1, 0]).steps;
// ["received 1001010", "syndrome H·rᵀ = 110",
//  "the lightest error with that syndrome is 0010000 (weight 1)", "corrected codeword 1011010, message 1011"]

A code with generator matrix GGG (k×nk \times nk×n) encodes mmm as mGmGmG. Put GGG in systematic form [Ik∣A][I_k \mid A][Ik​∣A]; then H=[−A⊤∣In−k]H = [-A^{\top} \mid I_{n-k}]H=[−A⊤∣In−k​] satisfies GH⊤=0G H^{\top} = 0GH⊤=0, and a word rrr is a codeword exactly when its syndrome Hr⊤Hr^{\top}Hr⊤ is zero. If r=c+er = c + er=c+e, the syndrome is He⊤He^{\top}He⊤, so decoding is finding the lightest error with that syndrome, the coset leader. In the Hamming code the columns of HHH are all non-zero vectors, so the syndrome of a single error is its position written in binary.

Distance and bounds

A code with minimum distance ddd corrects t=⌊(d−1)/2⌋t = \lfloor (d-1)/2 \rfloort=⌊(d−1)/2⌋ errors, because balls of radius ttt round the codewords do not overlap. Counting the words in those balls gives the Hamming (sphere-packing) bound, and a code that meets it is perfect:

Reed–Solomon

import { reedSolomon } from "@ratmath/discrete";
const rs = reedSolomon({ p: 11, n: 10, k: 4 });   // corrects 3 errors
const w = rs.encode([3, 1, 4, 1]);                // the values of 3 + x + 4x² + x³ at 1, …, 10
const y = w.slice(); y[0] += 1; y[5] += 3; y[9] += 7;   // three errors (mod 11)
rs.decode(y.map((v) => v % 11)).errors;           // [0, 5, 9]

A message is a polynomial fff of degree below kkk, sent as its values at nnn distinct points. Two such polynomials agree in at most k−1k - 1k−1 places, so the distance is n−k+1n - k + 1n−k+1, meeting the Singleton bound. Berlekamp–Welch decoding looks for an error locator EEE of degree eee (monic) and QQQ of degree below e+ke + ke+k with Q(αi)=yiE(αi)Q(\alpha_i) = y_i E(\alpha_i)Q(αi​)=yi​E(αi​) for every iii: a linear system over Zp\mathbb{Z}_pZp​. Then f=Q/Ef = Q / Ef=Q/E, and EEE vanishes at the error positions. The steps show the system, EEE, QQQ and the division.
